# V3 — Integração com APRS-IS

## Objetivo

A V3 evolui o APRS ESP32 Web Monitor para receber pacotes reais da rede APRS-IS pela internet, mantendo o painel web e o display OLED SSD1306.

Nesta versão, o ESP32 opera em modo somente recepção. Não transmite pacotes para APRS-IS e não recebe diretamente sinais de rádio.

## Funcionalidades

- Conexão Wi-Fi em modo Station.
- Ponto de acesso próprio em modo Access Point.
- Servidor web HTTP.
- Conexão TCP com APRS-IS.
- Login somente de recepção usando `pass -1`.
- Filtro de pacotes de posição.
- Histórico circular dos últimos 10 pacotes.
- API JSON para estado e pacotes.
- Atualização periódica do painel web e OLED.
- Tentativas automáticas de reconexão.

## Hardware

- ESP32.
- Display OLED SSD1306 I2C de 128 × 64 pixels.

### Ligações OLED

| OLED | ESP32 |
|---|---|
| VCC | Conforme a especificação do módulo |
| GND | GND |
| SDA | GPIO 21 |
| SCL | GPIO 22 |

O endereço I2C configurado no firmware é `0x3C`.

## Bibliotecas

Instalar pelo Arduino IDE:

- Adafruit SSD1306
- Adafruit GFX Library

As bibliotecas Wi-Fi, TCP, servidor HTTP e I2C são fornecidas pelo pacote de placas ESP32.

## Configuração

Antes de compilar, edite as constantes de Wi-Fi no início do arquivo `.ino`:

- `WIFI_SSID`
- `WIFI_PASSWORD`

Configuração inicial do APRS-IS:

- Servidor: `soam.aprs2.net`
- Porta TCP: `14580`
- Senha de recepção: `-1`
- Filtro: `t/p`

O identificador `N0CALL` é apenas um valor demonstrativo. A configuração destina-se a receber dados, não a transmitir.

## Acessos

### Painel web

Conecte o computador ou celular ao ponto de acesso `APRS-ESP32-V3` e acesse:

`http://192.168.4.1`

Senha inicial do ponto de acesso: `aprs12345`.

O painel também pode ser acessado pelo endereço IP atribuído ao ESP32 na rede Wi-Fi doméstica.

### API

| Rota | Descrição |
|---|---|
| `/` | Painel web |
| `/api/status` | Estado de Wi-Fi, APRS-IS, contadores e tempo ligado |
| `/api/packets` | Histórico de pacotes recebidos |

## Testes

1. Configure o SSID e a senha da rede Wi-Fi.
2. Selecione a placa ESP32 correta no Arduino IDE.
3. Compile e grave o firmware.
4. Abra o Monitor Serial a 115200 baud.
5. Conecte-se ao ponto de acesso do ESP32.
6. Acesse `http://192.168.4.1`.
7. Verifique o estado do Wi-Fi e da conexão APRS-IS.
8. Aguarde a chegada de pacotes e confira o histórico.

A recepção depende de acesso à internet, disponibilidade do servidor, configuração do filtro e atividade APRS-IS. Um histórico vazio não significa necessariamente que o firmware falhou.

## Limitações conhecidas

- Não há recepção de rádio pelo Baofeng ou por um TNC.
- Não há GPS.
- Não há transmissão de pacotes.
- O firmware armazena o texto bruto recebido, sem decodificar coordenadas e símbolos.
- O histórico é mantido em RAM e desaparece quando o ESP32 reinicia.
- A conexão APRS-IS utiliza TCP sem TLS nesta implementação.
