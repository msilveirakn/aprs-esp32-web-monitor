
# V1 — APRS ESP32 Web Monitor

## Objetivo

Criar a base de um sistema experimental de monitoramento APRS
utilizando ESP32, OLED SSD1306 e servidor web local.

## Funcionalidades

- Access Point Wi-Fi próprio.
- Servidor HTTP executado no ESP32.
- Painel web responsivo.
- Endpoint `/api/status` com dados do sistema.
- Exibição do IP, clientes conectados e tempo ligado no OLED.
- Atualização automática do painel a cada 3 segundos.

## Hardware

- ESP32 DevKit.
- OLED SSD1306 I2C 128x64.

## Ligações

| OLED | ESP32    |
|------|----------|
| VCC  | 3V3      |
| GND  | GND      |
| SDA  | GPIO 21  |
| SCL  | GPIO 22  |

## Bibliotecas

- Adafruit SSD1306
- Adafruit GFX Library

WiFi.h, WebServer.h e Wire.h são fornecidas
pelo ambiente de desenvolvimento ESP32.

## Rede

- SSID: APRS-ESP32-V1
- Endereço padrão: 192.168.4.1
- Página principal: /
- API de estado: /api/status

Não publique a senha Wi-Fi em um repositório público
se estiver usando uma senha pessoal.

## Limitações

Esta versão não recebe pacotes APRS reais, não se conecta
ao APRS-IS e não transmite por rádio.

Os dados exibidos são exclusivamente informações locais
do ESP32.
